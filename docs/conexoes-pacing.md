# Conexoes Level Pacing

Use this guide when creating new Conexoes levels, especially for the daily level routine.

## Difficulty Curve

- Levels 1-10: mostly obvious categories, everyday words, little overlap between groups.
- Levels 11-25: add one trickier group per level, but keep at least one easy anchor group.
- Levels 26-50: use two medium groups, one easier group, and at most one hard group.
- Levels 51-75: allow more wordplay, cultural references, and closer false matches.
- Levels 76-100: allow rare Portuguese words, historical/cultural categories, and subtle overlaps.
- Level 100+: very hard is allowed, but each level should still have one group that helps the player enter the puzzle.

## Theme Variety

- Fully themed levels, such as all food or all cities, are fun but should be occasional.
- Avoid placing more than two same-domain levels in a row.
- A strong level usually mixes domains: daily life, Portugal, language, culture, nature, sport, food, objects, geography, or wordplay.
- If all four groups share a broad theme, make two groups easy enough to identify quickly.

## Group Balance

- Every level needs exactly 4 groups of 4 words.
- Avoid repeated words inside the same level.
- Avoid groups that can be solved only by very obscure knowledge before level 50.
- Do not stack four difficult or very difficult groups before level 75.
- Prefer PT-PT words and categories.

## Daily Prompt Rule

When adding a new daily Conexoes level, first choose the target level number. Then build the level using the matching difficulty band above. The level should feel like a small step from the previous one, not a sudden jump.
